# Group seam and weight painting check

Import `group-seam.svg` as editable artwork. It contains two cubic strokes whose endpoints meet exactly at `(320, 300)`, with separate IDs and Bézier handles. The SVG group inside the importer group exercises nested weighted scope without requiring a saved rig.

## Acceptance checklist

1. Create an armature with at least two bones. Select the imported group, choose **Assign bones**, pick both bones and **Apply**. The pending result reads Weighted. Both paths bind in one undo step using automatic rest-space weights; the scope stays on the group while selecting bones. Artwork order, grouping and point positions remain unchanged.
2. Select the shared seam. The sidebar reports two shared points but counts one selected weight group. Change a selected-bone percentage or slider and confirm both endpoints preview and update together. The paths remain separate SVG geometry. Shift-click another point or drag a selection box, verify mixed values, then enter a percentage for the entire selection. Reducing a 100% influence to 60% gives the remaining 40% to other eligible influences.
3. Use **Make separate** for one seam point. Give the two endpoint groups different weights, such as 20% and 50%. Their overlapping marker opens a popover showing both groups and their separate percentages. Edit one group and verify the other stays unchanged. **Share weights at exact overlaps** deliberately rejoins them using the first owner's weights.
4. Select a Bézier handle and enable **Independent handle weights**. Change its weight without changing the anchor. Disabling the option restores anchor inheritance. An independent handle with no weights stays at rest when the bones are posed.
5. Lock an influence and run **Auto weights**. Verify a temporary preview for the selected groups, exact preservation of locked values, and explicit **Apply / Cancel**. Clear the selection to preview the whole scope. Slider, numeric and painting edits must preserve locks too. **Clear weights** leaves selected groups at rest and refuses positive locked weights until unlocked.
6. Try **Add**, **Subtract**, **Set** and **Smooth** with both bone influences available. Verify temporary color previews during a stroke, one undo step on release, and no saved change after Escape or focus loss. Selected owners restrict the brush; clear the selection to include all eligible points. Painting an inherited handle updates its anchor group; an independent handle paints separately. Repeating strokes builds on the committed result.
7. Switch **Weights for** to **Bone** and inspect controlled points across both paths. Toggle the zero-weight filter. Alt-click an overlapping marker while painting to inspect separate groups; use **Add group** to include both without merging them. Space paints a focused point. Ctrl/Cmd+A on the weight canvas selects weight points without changing artwork selection.
8. Use **Edit bones** to reduce to one bone. Conflicting locks must be unlocked first; the result is rigid, with all affected groups at 100%, and painting unavailable. Add a second bone to initialize automatic weights again. Add a third to an already weighted assignment and verify existing manual weights remain unchanged with the added influence at zero. Removing every assigned bone unbinds while preserving the visible artwork.
9. Undo/redo a completed weight edit, then save/reload. Group scope, explicit shared owners, independent handles, percentages and locks persist in document v14 / rig v5. Reopening an older single-bone binding with empty weights labels it Custom weights and preserves those points at rest. Static SVG exports the posed artwork without weight overlays. Bone keyframes and animated rig export remain outside this fixture's scope.

Atomic failure checks: add a native shape, lock a descendant, or pre-bind one child before attempting complete group binding. The command should explain the problem without partially binding the remaining paths. Unbinding a path that owns shared weights must preserve the surviving path's effective values and current artwork.
